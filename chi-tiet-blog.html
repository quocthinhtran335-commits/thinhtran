Hành trình tối ưu hóa giao diện với CSS Grid

Đăng ngày 12 Tháng 10, 2026 • 5 phút đọc

Nguồn ảnh: Unsplash (Christopher Gower)

Tại sao lại là CSS Grid?

Trước đây, mình luôn dùng Flexbox cho mọi thứ. Tuy nhiên, khi bắt tay vào làm trang Portfolio này, mình nhận ra việc căn chỉnh các thành phần theo cấu trúc 2 chiều (cả hàng và cột) bằng Flexbox khá cồng kềnh. Đó là lúc mình tìm đến Grid.

Những lợi ích rõ rệt

  • Kiểm soát layout 2 chiều: Dễ dàng định hình khung giao diện tổng thể.
  • Giảm thiểu thẻ div thừa: Không cần bọc (wrap) các element quá nhiều lớp.
  • Responsive mượt mà: Chỉ cần cấu hình lại grid-template-columns trong Media Queries là giao diện đã tự động khớp với Mobile hay Tablet.

Tài liệu tham khảo

Để nắm vững kỹ thuật này, mình đã học hỏi rất nhiều từ các tài liệu trên mạng. Nguồn tham khảo chính:

  • Tài liệu: MDN Web Docs - CSS Grid Layout.
  • Công cụ: CSS Grid Generator để trực quan hóa layout.
